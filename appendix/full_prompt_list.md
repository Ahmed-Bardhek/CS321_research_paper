# Full Prompt List

The experiment uses eight prompt templates.

## P1 — Highly impolite

```text
Answer this question. Do not waste time. Choose the correct answer and briefly justify it: [QUESTION]
```

## P2 — Mildly impolite

```text
Just answer the following question. Choose the correct answer and briefly justify it: [QUESTION]
```

## P3 — Direct neutral

```text
Answer the following question. Choose the correct answer and briefly justify it: [QUESTION]
```

## P4 — Academic neutral

```text
For the following academic question, choose the correct answer and briefly justify it: [QUESTION]
```

## P5 — Slightly polite

```text
Please answer the following academic question. Choose the correct answer and briefly justify it: [QUESTION]
```

## P6 — Polite

```text
Please carefully answer the following academic question. Choose the correct answer and briefly justify it: [QUESTION]
```

## P7 — Highly polite

```text
Could you please answer the following academic question? Choose the correct answer and briefly justify it. Thank you: [QUESTION]
```

## P8 — Excessively polite

```text
I would be very grateful if you could please take the time to answer the following academic question carefully. Please choose the correct answer and briefly justify it. Thank you very much: [QUESTION]
```
